# Channel360 Git Baseline

The repository baseline is prepared on local branch `main`. The complete source set, README, migrations and dependency lockfiles are included. The staging set is limited to source, safe synthetic M0 input workbooks, and credential-free UI screenshots.

Excluded local state includes `.runtime/`, `.venv/`, `node_modules/`, `.env` files, PGPASSFILEs, local auth keys/tokens, generated downloads, database/service state, browser traces/videos, test results and generated workbook outputs.

The public GitHub push is performed only after a full staging review and secret scan. See top-level README and current security report for product status.
